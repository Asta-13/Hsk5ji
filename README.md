# Өдрийн reel бот (Шат 1)

Өдөрт 4 удаа, 6 цаг тутамд (Улаанбаатарын цагаар 06:00, 12:00, 18:00, 00:00) GitHub өөрөө нэг HSK үгийн богино босоо видео (reel) хийж `reels/` хавтаст хадгална.
Үгийг **HSK 1-ээс эхлээд** дарааллаар нь авч, HSK 2, 3... рүү шилжинэ (`reels/state.json` дээр хаана явааг тэмдэглэнэ). Сүүлийн 60 видеог үлдээж, хуучныг нь автоматаар устгана.
Видео: Хятад хэлээр эхлээд удаан, дараа нь хэвийн уншина → монгол тайлбар → (байвал) жишээ өгүүлбэр → давталт.
Видеоны хажууд `reel-0001.txt` (видеотой ижил дугаар) нэрээр Instagram-д хуулах монгол тайлбар (caption) + hashtag гарна.

## Утаснаас яаж ашиглах вэ
1. GitHub аппаар/хөтчөөр репо руугаа ор → `reels` хавтас → `reel-0001.mp4` (дугаар нь үгийн дараалал) → **Download** (эсвэл «Raw» дээр удаан дараад хадгал).
2. `reel-….txt`-ийг нээж тайлбарыг хуулна.
3. Instagram → **+ → Reel** → татсан видеог сонгоод, тайлбараа буулгаж оруулна.

## Шууд (гараар) ажиллуулах
Репо → **Actions** → **Daily reel** → **Run workflow**. Хүсвэл тодорхой үг (жишээ `爱`) эсвэл түвшин (1–6) өгч болно.

## Анхаарах зүйл
- Репо дээр Actions асаалттай, **Settings → Actions → General → Workflow permissions** нь **Read and write** байх ёстой.
- Дуу хоолой нь `edge-tts` (Microsoft) ашигладаг: хятад `zh-CN-XiaoxiaoNeural`, монгол `mn-MN-YesuiNeural`. Дуу үүсгэж чадахгүй бол видео хадгалагдахгүй, ажиллагаа алдаатай болно.
- Шат 2 (автоматаар Instagram-д оруулах) хараахан хийгдээгүй.
