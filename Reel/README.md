# Reel бот

GitHub Actions өдөрт олон удаа HSK видео (reel) үүсгэж `reels` салбарт хадгална.

- **Daily reel** — HSK үг тус бүрийн видео (удаан → хэвийн дуудлага → монгол тайлбар → жишээ → давталт).
- **Daily scene** — 40 богино харилцан яриа (амьд ярианы хэв маяг, дүрүүд ярихад ам нь дуутай хамт хөдөлнө).

## Файлууд хаана байх вэ
`reels` салбар → `days/ӨӨӨӨ-СС-ӨӨ/` (Улаанбаатарын өдөр) дотор тухайн өдрийн бүх видео + `.txt` тайлбар,
мөн `days/ӨӨӨӨ-СС-ӨӨ.zip` нэг дор татахад зориулсан. Сүүлийн 3 өдрийг үлдээнэ. Хуучин файлууд `days/legacy/` дотор.

## Найдвартай ажиллуулах (schedule)
GitHub-ийн `schedule` үргэлж ажилладаггүй (ихэнхийг алгасдаг). Тогтвортой болгохын тулд cron-job.org-оор гаднаас дуудна:
1. GitHub → Settings → Developer settings → Fine-grained token: зөвхөн энэ репо, **Actions: Read and write**.
2. cron-job.org → шинэ job, 15 минут тутамд, `POST https://api.github.com/repos/Asta-13/Hsk5ji/actions/workflows/daily-reel.yml/dispatches`
   Header: `Authorization: Bearer <TOKEN>`, `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`
   Body: `{"ref":"main","inputs":{"auto":"true"}}`
3. Scene-д мөн адил `daily-scene.yml`-ээр өөр job (3 цаг тутам).
`auto=true` үед хоорондын хугацаа (reel 50 мин, scene 230 мин) хүрээгүй бол ажил өөрөө алгасна.

## Алдаа гарвал
Actions → улаан run → улаан алхамын лог. Дуу үүсгэх алхам 3 удаа дахин оролддог; гацвал 10 минутын дараа
хаана гацсаныг лог руу хэвлээд зогсоно.

## Видеоны чанарын тохиргоо (daily-reel)
Орчны хувьсагчаар (workflow-ийн `env:` хэсэгт) тохируулна:
- `REEL_CRF` — эцсийн видеоны чанар, анхдагч `22` (бага = чанартай/том, 18–26).
- `REEL_DITHER` — дэвсгэрийн градиентын зэрэглэлийг (banding) зөөлрүүлэх «үр», анхдагч `0` (унтраасан). `0.8` гэвэл зөөлөн болно, гэхдээ файл ~2–3 дахин томорно.
- `REEL_FADE=0` — дэлгэц солигдох бүдэг шилжилтийг унтраана.

Дэлгэцийн байрлал Instagram Reels-ийн UI-д халхлагдахгүйн тулд `SAFE_TOP`, `SAFE_BOTTOM`, `PAD` (make_reel.py) дотор тохирсон.

## Цуврал: дугаарлалт ба холбоо (`series.py`)
Бүх видео төрөл бүрээрээ **#1, #2, #3 …** гэж дугаарлагдана (файлын нэр, дэлгэцийн баруун дээд булан, тайлбар). Төлөв нь `reels` салбарын `series.json`.

| Төрөл | Файл | Тайлбар |
|---|---|---|
| Үг | `reel-0109.mp4` | олон үсэгт «хэрэгтэй» үг, 1 үг = 1 видео, жишээ өгүүлбэртэй |
| Энгийн үг | `words5-0001.mp4` | нэг үсэгт үгс **5-аар** нэг видеонд, жишээгүй, хятад + пиньинь + орчуулга |
| Дүрэм / Яриа / Тон / Шалгалт | `grammar-` `scene-` `tone-` `quiz-` | |

**Холбоо:** `level` = сүүлд гарсан «Үг» видеоны HSK түвшин. Дүрэм, яриа, энгийн үг тэр түвшнээс сонгогдоно; шалгалт зөвхөн аль хэдийн заасан (Үг + Энгийн үг) үгсээс; тон нь заасан үгсийн үсэг хамгийн их орсон багцыг түрүүлж авна. Тайлбар бүрд «📚 Цуврал · HSK 1 — Үг №109 · Дүрэм №8 …» мөр орно.

**Гараар засах:** `word_overrides.json` — `simple` (энгийн үг болгох), `needed` (нэг үсэгт ч тусдаа видео болгох), `skip` (хийхгүй), `pinyin_fix` (эх өгөгдлийн буруу пиньинь). `python3 Reel/series.py status` — хэдэн үг үлдсэнийг харуулна.
Гараар `--word`/`--index` өгвөл дугаар, төлөв өөрчлөгдөхгүй.
