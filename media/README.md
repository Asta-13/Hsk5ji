# media/ — өөрийн mp3 / mp4 файлууд

1. `нэр.mp3` (эсвэл .mp4) файлаа энд хийнэ. Нэрийг латин үсэг, цифр, `-` `_`-ээр бич.
2. Дууны үгтэй бол ЯГ ТЭР НЭРЭЭР `нэр.txt` үүсгэнэ. Мөр бүр:
   `中文 | монгол орчуулга`  (орчуулга заавал биш; `#` -ээр эхэлсэн мөр тайлбар)
   → Whisper дууноос цагийг нь олж, мөр бүрийг дуутай таарууллаа.
3. `.txt` байхгүй бол Whisper өөрөө хятад хадмал гаргана (🤖).
4. Файл хэмжээ < 100MB. mp3 ~128kbps, mp4 720p байвал сайт хурдан:
   `ffmpeg -i in.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 96k out.mp4`

## TikTok маягийн лент
Богино (≤ 1-2 мин) mp4 клипүүдээ (TikTok г.м.-ээс хайчилсан) энд хийхэд **🔥 Лент** хэсэгт босоо гүйлгэгчээр автоматаар тоглоно:
хятад хадмал (пиньинь-тай) цагтай гарч, үг дээр дарвал тайлбар, 📚 дээр дарвал шинэ үгсийг нэг дор нэмнэ.

## mp3 нэмсэн ч сайтад гарахгүй бол
1. Файл **яг `media/` хавтсанд** байгаа эсэх (`reels/`, `video/` эсвэл өөр хавтас биш). Хавтас дотор хавтас байж болохгүй.
2. GitHub → **Actions → Transcribe media** ажилласан эсэх (ногоон ✓). Улаан бол лог дотор шалтгаан бий. Гараар: *Run workflow*.
3. Дууны үгтэй бол `нэр.txt` хийвэл хамгийн найдвартай (Whisper дууг хөгжмөөс таньж дийлдэггүй).
4. Хадмал олдоогүй ч файл **Дуу** хэсэгт тоглуулагчтай гарна. mp3 нь **🔥 Лент** дотор диск/эквалайзертай слайд болно.
5. Утсан дээр хуучин харагдвал сайтыг нэг дахин нээнэ (service worker шинэчлэгдэнэ).

## 🌍 Дэлхий хэсэг (улс орон · сансар · түүхэнд өнөөдөр · урам)
Агуулга нь `data/world.json` дотор. Шинэ баримт нэмэхдээ `items` дотор мөр нэмнэ:
`{"id":"w94","cat":"country","e":"🇲🇳","d":"","y":"","t":"Гарчиг","zh":"中文 өгүүлбэр。","mn":"Монгол орчуулга"}`
- `cat`: `country` · `space` · `culture` · `history` · `wisdom`
- `history`-д `d` = `"MM-DD"` (жишээ `"11-18"`), `y` = он өгвөл тухайн өдөр нүүр хуудсанд автоматаар гарна.
- Хятад өгүүлбэр дэх HSK үгс автоматаар пиньинь-тай, дарж сурдаг болно.
